# dsh-preset-rules

[English](README.md) | [简体中文](README.zh.md)

用一份可编辑的规则文件管理 DeepSeek Harness 的 Agent 预设——每次启动重新生成，dsh 升级后预设不会悄悄过期。

`dsh-preset-rules` 是一个 dsh bundle，内含一个 Host 插件。它在启动时读取当前安装随附的 preset 声明，按规则算出结果，写到 `$DSH_HOME/cordis.patch.yml`。这个文件是普通的 dsh patch 层：dsh 会在 profile 层之后应用它，文件变化时由 watcher 自动重新组合。

## 为什么要「生成」而不是手写覆盖

手写的覆盖会过期：dsh 新版本往预设里加了行，冻结的副本会静默丢掉。每次启动重新生成，快照永远是新的，而且产物仍是一个可读、可 diff、可直接删除的 YAML 文件。

## 要求

- dsh 0.2.x
- Node.js >= 20（随附运行时更新）

## 安装

```sh
dsh plugin --profile <profile> add <本包>
```

或者在 Harness 界面里用插件管理器安装（Creator 模式写的是同一份 bundle patch）。

然后写规则文件：

```sh
node bin/preset-rules.js --init     # 生成一份带注释示例的模板
```

```sh
# $DSH_HOME/preset-rules.rules
presets = all; entry = id: time-context; action = hide()
```

插件不会自己写规则：没有规则文件时它每次启动打一行提示（避免首次安装完全静默），除此之外不做任何改动。

先跑 `check` 模式——把插件配置里的 `mode` 改成 `check`，或者直接用 CLI：

```sh
node bin/preset-rules.js --check
```

它只打印将要发生的变化，不写盘。确认无误后再切回 `apply`（默认值）。

## 规则

一行一条，三个子句用 `;` 分隔（顺序无关）：

```
presets = all; entry = id: time-context; action = hide()
```

| 子句 | 取值 |
|---|---|
| `presets` | `all`、单个 id、`{a, b}`、`not(x)`，以及它们之间的 `+` / `-` |
| `entry` | `*`、`id: 值`、`name: 值`、`{a, b}`、`not(...)`、`+` / `-` |
| `action` | `hide()`；`disable()`、`enable()`、`set(path, value)` 为 0.2 预留 |

二元 `+` / `-` 两侧必须有空格；标识符里可以出现 `-`、`.`、`@`、`/`。`#` 起注释。

示例：

```
presets = not(minimal); entry = id: time-context; action = hide()
presets = {standard, cordis}; entry = not(id: persona); action = hide()
```

诊断信息带 `文件:行:列`。未知 preset、规则一处都没匹配到是警告；语法错误、未知动作、预留动作会中止本次生成并保留旧文件。

## 模式

| mode | 行为 |
|---|---|
| `apply`（默认） | 校验通过且字节有变化才写 |
| `check` | 只计算并打印，不写盘 |
| `off` | 什么都不做 |

## CLI

```sh
node bin/preset-rules.js [--check|--apply] [--rules <file>] [--target <file>] [--source <dir>] [--json]
node bin/preset-rules.js --init [--rules <file>]
```

默认路径：`$DSH_HOME/preset-rules.rules` 与 `$DSH_HOME/cordis.patch.yml`。`--source` 指向 `@deepseek-ai/dsh-web-app` 包目录；桌面安装与 npm 安装都能自动识别。读取打包在 `app.asar` 里的文件需要 Electron-as-node——桌面版本就是这个运行时。

## 生成物

```yaml
# generated by dsh-preset-rules 0.1.0 — do not edit
# source: @deepseek-ai/dsh-web-app 0.2.2-rc.1
# source-hash: sha256:…
# rules-hash: sha256:…
- id: preset-cordis
  name: '@deepseek-ai/dsh-agent-preset'
  config:
    id: cordis
    order: 4
    plugins: [ … ]
```

不含时间戳：相同输入产生相同字节，无事可做的启动不写任何东西。

这个文件归本插件所有。首行不是上面的标记时它会拒绝覆盖——手写的 patch 请放到 profile 层。

## 卸载

移除插件，然后删除 `$DSH_HOME/cordis.patch.yml`（或清空规则文件后启动一次）。生成层是全机器共享的，同一台机器上的所有 profile 都会用到它。
